# 冰哥申论强化课 Skill 使用说明

本包把25节强化课文稿与268页讲义中的方法整理成可调用的写作规则，覆盖48道小题、12篇大作文。它是强化课补充包，不是课程逐字稿或官方答案集。

## 直接使用

在支持自定义 skill 的平台，把整个文件夹放入该平台指定的技能目录，保留 `SKILL.md` 和 `references/` 的相对位置。是否自动触发由具体平台决定。

在普通对话中，上传完整阅读版，或上传压缩包并要求助手先读取文件。然后发送题干、要求与材料：

> 请使用“冰哥申论强化课 Skill”作答。先判断任务与材料结构，按相应题型规则组织。小题不自由发散，不同层级不因同词合并；作文先找总分论点，再论证。下面是题目和全部相关资料……

只想要答案，可追加：

> 只输出可直接使用的参考答案，严格控制字数，不附分析。

需要学习过程，可追加：

> 请给简短审题定位、材料依据与结构、参考答案，再说明本题最值得迁移的三个方法。

批改时：

> 按任务、结构、要点、逻辑、表达、字数格式检查我的答案，指出具体依据并给改写；没有官方细则时不要伪精确评分。

## 文件怎么读

| 文件 | 用途 |
|---|---|
| `SKILL.md` | 助手入口：触发条件、总流程、题型路由和输出约定 |
| `references/00-common.md` | 通用判断：审题、总分、案例、合并、因果与压缩 |
| `references/01-summary.md` | 归纳概括 |
| `references/02-solutions.md` | 提出对策与启示 |
| `references/03-analysis.md` | 综合分析 |
| `references/04-practical-writing.md` | 应用文及各文种 |
| `references/05-essay.md` | 大作文：立论、论证、材料改写、策论 |
| `references/06-output-review.md` | 输出、批改、复盘、局部示范和验收场景 |
| `references/07-case-index.md` | 60道课堂训练的主题、页码和方法索引 |
| `references/08-sources.md` | 来源、OCR、转录修正与课堂经验边界 |
| `冰哥申论强化课Skill_完整阅读版.md/.docx` | 汇总阅读文件，便于保存、阅读和重新上传 |

## 使用时的三个约定

1. 任务与材料优先于模板。旧题提供判断方法，不提供可以无条件复制的新题答案。
2. 本包保留老师的解题与论证风格；不采纳编造名人讲话、事实数据的方法，也不把课堂分数预测当官方标准。
3. 保存文件不等于助手跨对话永久记忆。新对话应重新上传或确保平台已加载；已有理论课 skill 尚未在本包中合并。

版本：1.0，强化课独立版。材料覆盖与编校记录见来源说明。
