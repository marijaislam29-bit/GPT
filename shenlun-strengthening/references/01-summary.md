# 归纳概括强化规则

对应课01—05，讲义印刷页2—41；归纳概括共15题。课06对“亮点”和“三条黄河”的复盘也应结合使用。

## 1. 执行顺序

1. 把任务翻译成“我要找谁的什么”，圈出限定词。
2. 按主体、内容、工作环节及时间变化划大层次。
3. 在每层内找总结，再核对案例的独立信息。
4. 根据任务选择动作、问题、效果等表达，不按词性机械筛选。
5. 同层同义才合并，先保证层级，再精简字数。
6. 用序号、核心句和必要分段呈现；一段话题按要求连贯成段。

## 2. 不同任务的具体处理

### 2.1 概括经验做法

先明确要推动的工作，再找为实现这一工作采取的措施。结果性表述若同时说明推进机制，不能因出现“提升、形成”就一概剔除。

推荐表达：`核心做法＋具体动作/机制＋必要的对象或作用`。不是每点都必须写效果，也不为了凑全“主体动作结果”而加材料没有的内容。

**社区基金（训1，课01，印刷页2）**：先建立、完善基金参与体系，再规范资金管理，继而用基金开展治理服务。筹集与使用是不同工作层面；同样出现“拓宽资金来源”，未必可跨层合并。“义剪美”等案例用于证明服务机制，不需要逐项抄项目故事。

**铁路物流（训2，课01，印刷页4）**：不能把“提供”和“优化”机械拆成两问。应看材料是否按这两个词分层。大宗货物与散杂货运输虽对象不同，但部分措施共同针对运输成本，可按共同机制合并；总体服务对象的多元性则可作为总结。先判总分，再保留降低费用、提升运力、总包和全流程服务等具体内容。

**土味变品味（训3，课01，印刷页7）**：不能看到产品销售到国外就都归为“拓销路”。分别抓案例中的关键转变机制：电商销售、加工提升、传统技艺、农文旅融合等；结合总领和人物行动，关注带头人的作用。材料只讲坚守传统，不能擅加“守正创新”中的创新。

### 2.2 概括问题：先判“问题”的含义

**幼儿教育（训4，课02，印刷页9）**：课堂通过“不平衡、不充分”组织答案，保留材料中不同类型幼儿园的差异及其“已有进展但仍有短板”的关系。不能无视材料划分，一律压成“公办/民办”，再把某一类师资问题扩展到所有幼儿园。

这不意味着凡“概括问题”都要写成绩；本题写进展是为了说明材料的结构及不平衡关系，不能移植为所有问题题的固定要求。

**新民乐（训5，课02，印刷页12）**：“这些议论主要涉及哪些问题，并分别说明”，这里的“问题”是讨论议题。先提炼共同议题，再归入不同观点；不是只找负面，也不是粗分支持与反对。

议题可涉及走红的价值、如何创新、概念界定、发展道路等，具体维度必须由发言内容归纳。表达形态为：`某议题：一方认为……；另一方认为……`，有的议题只有同向观点，就不编造反方。

### 2.3 用一段话概括复合信息

**乡村新职业（训6，课02，印刷页14）**：题干明确“不同领域＋新职业＋对乡村发展的推动作用”。每个领域都按这条信息链取点，最后按要求连成一段。

可以用一个短总括起句，随后用分号衔接不同领域；不能把答案写成四个大段。篇幅分配按四则资料总体控制，不让第一则占去大半。

两项重点校验：

- 职业的任职要求、个人能力，不等于职业对乡村发展的作用。
- 当地原有项目、资源、产业规模，不等于新职业到来之后产生的效果。

### 2.4 概括特点、亮点、智慧、“巧”在哪里

先把抽象任务词放回材料，不自创通用定义。可以有“共同含义＋具体体现”，但共同含义必须覆盖具体部分。

- **绿色工厂（训7，课03，印刷页19）**：“绿”围绕绿色低碳展开。环境、生产产品、办公、原材料等，只要材料支持，都可成为体现；不要只找字面出现“绿”的句子。
- **生态实践智慧（训8，课03，印刷页21）**：在材料中理解为人与自然相互适应。种植地点选择、漏斗架、庭院小气候、生活与农业互动、绿色材料及生态作用分别核对。写“因地制宜”不能吞掉不同层面的具体智慧。
- **智慧养老（训13，课05及06，印刷页34）**：材料按家属监测、适老使用、生活服务、安全保障等实际亮点呈现，不能看到“线上/线下”就强拆。本题可以概括举措带来的好处；“所有亮点题只写意义”则是错误推广。
- **大桥之巧（训14，课05，印刷页35）**：既有桥自身的景观、改建技术、连接设计，也有带动发展的作用。拆与建能否合并，取决于是否同属改建技术及篇幅；不能强行全部改为单一的做法或意义。

### 2.5 解释角色变化、身份变化的原因

**窑洞修复（训10，课04，印刷页26）**：先把“旁观者—参与者—传承者”作为待核验的结构。材料主要讲三个身份的表现，只在部分环节给出转变原因，就按这一结构写，不能为凑“原因题”把每层都强改成原因。

可先用短句概括观念和参与程度的变化，再分别说明。课堂的这一总括属于可用组织方式，不意味着原材料已有完全相同的总括句。

### 2.6 介绍模式、概况或复合任务

**工业上楼（训12，课04，印刷页31）**：本质是概括介绍，不因“介绍”二字就加公文格式。区分省级模式总结与城市案例，形成总分；不要凭自己习惯生造“背景—概念—意义—问题—做法”五栏。不能把生产、生活、研发等词硬拆为并无充分对应材料的结构。

**三条黄河（训15，课05，印刷页38）**：先解释三者分别是什么，再回答如何协同。材料核心结构是科技总领，下分数字孪生黄河和模型黄河如何服务实体原型黄河；没有给出三者任意两两互动，就不补造完整互动矩阵。

**融合型大社区（训11，课04，印刷页28）**：只选解决所问新问题的新解法，不是把一切好做法都抄入答案。技术、网格和多元协作要看各自解决什么；走街串巷与防止重复报送等，也可能是解决问题的独立要求，不能让过窄小标题漏掉它们。

## 3. 核心词和小标题

- 优先原文直接表达；没有时提炼准确的共同意思。
- 核心词不是为了对仗而造一个大词，更不是脱离展开单独计数。
- 短而明确的要点可以直接写，不必再加同义小标题。
- 不能压缩掉区分该点的关键修饰，如只写“平台、能力、模式、机制”。
- 对不确定的同义表达，可在不重复堆砌的前提下保留核心原词和解释，兼顾准确与清晰。

## 4. 交卷前自检

答案是否逐项回答题干？“总”是否覆盖后面的所有点？同级项目是否同层？合并是不是仅因为同词？不同主体的情况有没有被错误扩展？每点能否回到材料找到依据？题干要求的一段话、分别说明、字数限制是否做到？
