## 2. 如何核对来源

讲义没有可直接使用的完整中文文本层，因此对268页逐页进行中文文字识别。空白页、章节页和答题格页文字少属于正常情况。OCR用于检索与题干定位；疑似转录错误、关键题型和任务要求结合版面及上下文核对。

文稿完成全文提取后，按任务词、方法提示、答案组织、课堂纠错和材料关系检索，分课阅读相关语段，再进行跨课复盘和讲义交叉核对。本包是方法提炼，不保留课程闲聊、广告、歌曲和重复激励。

页码以讲义底部印刷页为准。封面和目录占连续PDF前6页，定位换算见[例题索引](07-case-index.md)。不以转录稿中口述的年份、卷别或人名作为唯一证据；本包也未额外核验题目在考试官网上的版本。

## 4. 三种内容层次

### A. 课堂明确讲授的方法

例如材料逻辑、总分优先、案例与总结、以逻辑定答案、带题阅读、分问呈现、作文关键词、案例共性、论证方式、改写材料。这些构成 skill 的主体。

### B. 从例题推得的边界与执行化整理

例如“覆盖检验三步”“任务清单”“材料工作表”“批改层级”“验收场景”，以及把课堂分散纠错组织为条件表。这些是整理后的操作工具，不声称老师原课就有同名步骤或表格。

### C. 编校修正与保留意见

以下内容进行了核对或明确限制，避免把口误、特殊经验和事实错误变成长期执行规则。

| 原文/课堂中容易引发的误解 | 本包处理 |
|---|---|
| “利里利”“利理力”等转录 | 按讲义作7确认“力、理、利” |
| “重系”等转录 | 析1按题目确认“种戏” |
| “数字栾城黄河”等转录 | 按材料处理为数字孪生黄河 |
| “存食、遇人、自证”等转录 | 应4按语境处理为存史、育人、资政 |
| 应13像民生宣传稿 | 讲义明确为全龄友好主题短评，保留指定标题和文体 |
| 乐源/乐园、新研/新能源眼镜等 | 应3以讲义“乐原市、新远眼镜公司”为准 |
| 没要求一一对应就可任选形式 | 若题目另明确先梳理完全部问题，优先遵守该顺序 |
| “有针对性就得写问题” | 采用老师明示的纠正：不能仅凭这一要求新增问题任务 |
| “亮点只能写意义” | 课06复盘明确亮点可写做法或意义，取决于材料 |
| “左右”一律允许上下浮动50字 | 不固化为统一考试规则；按具体题目、答题卡与官方要求 |
| “只考逻辑、不考小点” | 执行为结构与核心要点并重，不以此遗漏必要信息 |
| 课堂允许编造案例、领导讲话 | 不采纳；用可靠事实、材料原句或无归属的道理论述 |
| 宽泛解释行政执法为机关工作 | 只用于理解该题材料的关联，不把它当法律定义 |
| 一定得多少分、某省必怎么阅卷 | 视为课堂经验或激励，不冒充官方评分和录取结论 |

## 5. 与已有理论课 skill 的关系

本次没有收到理论课 skill 的原文，因此本包保留强化课独立结构。未声称已经实现与其条款级合并。

以后合并时，优先做“基础规则→强化补丁→适用条件→课堂反例”的对应表；重复的基础流程可压缩，分歧先检查题目条件与后续明确修正，避免把两套规则简单叠加。
