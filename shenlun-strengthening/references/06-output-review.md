# 输出、批改与一到N复盘

本文件把课堂“方便阅卷、复盘逻辑、旧题迁移”的要求转成执行模板。模板为整理者设计，不是老师逐字提供的标准答案格式。

## 1. 四种调用模式

### 模式一：考场作答

只给符合任务、文体、字数的参考答案。小题显式分问、分点；应用文用对应格式；作文交付完整文章。除必要材料缺失提示外，不附长篇教学说明。

### 模式二：学习详解

依次输出：

1. 审题定位：对象、问数、范围、关键限制。
2. 结构依据：材料大层次与任务的对应，用简明表或短段表达。
3. 参考答案：独立可用，不依赖前面的分析才能理解。
4. 方法提炼：说明本题一至三个关键判断，如为何不能合并、因果方向是什么。

只展示可检验的依据和结论，不用冗长内部推理淹没答案。

### 模式三：批改

先给总诊断，再按问题严重性检查：

| 层级 | 主要检查 | 修改方向 |
|---|---|---|
| 任务 | 漏问、对象错、范围错、文体错、要求未执行 | 先把必须回答的内容和交付形式纠正 |
| 结构 | 总分混排、维度重叠、不同层合并、比较未对齐 | 重新分层并解释依据 |
| 要点 | 漏点、多写无关点、改写失真、主体/时间错位 | 对照材料指出来源和缺口 |
| 逻辑 | 因果颠倒、把局部当整体、论据不证明论点 | 修复关系与论证桥 |
| 表达 | 空话、重复、搭配错误、缺必要修饰、语气不适 | 精简并具体化 |
| 呈现 | 字数、分段、标题、称谓、落款 | 按具体要求调整 |

建议使用：`原句/原结构 → 问题 → 材料或题干依据 → 改法`。

不能因为答案没用老师同一措辞就判错；应检验是否回答同一任务、保持同一层级、准确覆盖意思。老师的参考答案也是一种有依据的组织方案，不把“与参考不同”本身当扣分理由。

没有官方评分标准时，不报伪精确分数、不承诺某类文必得多少分。可说“任务完整但结构有两处明显问题”等；用户要求估分时，说明估分依据与不确定性。

### 模式四：一到N复盘

先复盘原题，再迁移，避免尚未做明白就无限改编。

一题形成一张卡：

`原任务｜材料骨架｜关键要点及来源｜老师纠错｜可迁移的材料关系｜不宜迁移的个案条件`

再按需扩展：

- **改设问**：从做法改为成效、原因、启示，分别重新选择材料，不能沿用同一答案。
- **改文种**：同样材料改成报告、倡议、宣讲，重审身份、受众与目的。
- **转作文**：从小题提炼一个核心话题，把做法、结果改写为分论点支撑；不能只把小题答案加长。
- **转论证段**：同一案例练“主体—做法—结果”“过去—现在—得益于”，检查各自证明什么。
- **分类复盘**：可按话题、设问或材料结构归类；方法迁移优先比较结构和任务，而不是只找相同题型名称。

## 2. 三个局部改写示范

以下为根据课堂材料重新组织的局部示范，不是老师逐字参考答案，也不代替原题完整作答。

### 示例A：保留有效信息，删除无效具体

不佳：`搭建平台，提升能力，构建新模式。`

改进：`搭建社区需求与资源对接的公益平台，提升招引专业社会组织、链接多元资源的能力。`

依据：社区基金题。删掉关键修饰后，“平台、能力、模式”几乎没有可识别的信息。精简应删故事细节，不能删实义。

### 示例B：问题开放，但建议要对症

不佳：`解决农创客融资问题，完善公共服务。`

改进方向：`围绕缺少抵押物、还款周期不匹配等原因，组织金融机构优化产品与期限安排，运用材料已有的乡村创客贷等支持创业。`

依据：农创客题。措施需要对准原因，不能为写得“大”而变成笼统公共服务。具体制度设计仍须在题设权限和材料条件内。

### 示例C：补上因果方向与论证桥

不佳分论点：`发展人工智能，需要提高发电效率。`

改进分论点：`以人工智能优化发电决策，提升电力生产效率。`

可用论证：`面对来水预测和机组调度的复杂约束，材料中的AI模型通过预测来水、推演水位、辅助调整机组参数，把决策依据前移，从而服务发电与防洪统筹。`

依据：作文训11。材料在说明AI带来什么，不是在说明提高效率是发展AI的前提。例子后说明机制，才完成论证。

## 3. 方法验收场景

以下用于检查本 skill 是否真正起作用。拿到相似题时，应出现右栏行为，不要求记忆旧题措辞。

| 场景 | 应有行为 | 不合格表现 |
|---|---|---|
| 只要求建议，附“针对性强” | 识别为建议任务 | 自动加一大段问题 |
| 要求先梳理完全部问题 | 严格先问题、后建议 | 因课堂说灵活而逐项穿插 |
| 新民乐讨论“涉及问题” | 提炼议题及相应观点 | 只摘负面现象 |
| 四则职业材料，一段话 | 对齐领域—职业—乡村作用 | 四段列举、任职要求占大半 |
| 三个市场分别解决问题 | 保留市场边界及对应 | 见“设施”就跨市场合并 |
| 小沈经验启示基层政府 | 转换为政府可做的行动 | 继续以小沈为所有句子的主语 |
| 林票已取得的成效 | 筛选已发生、改革带来的结果 | 把改革前动员当改革成效 |
| 理解“种戏” | 只围绕种戏整体解释并展开 | 机械拆成唱戏、种戏两问 |
| 只写报告两部分提纲 | 直接问题、建议 | 加完整调研报告长开头 |
| 给领导起草企业宣讲 | 以企业为实际受众 | 写“向领导汇报调研成果” |
| 全龄友好训13 | 按短评写观点与支撑，保留题目 | 写成办事宣传清单 |
| 创新创造材料未作区分 | 整体立论，找共性路径 | 先按字典拆两大分论点 |
| 精度温度力度由数字化带来 | 在论点中保留共同机制 | 只泛谈三种好品质 |
| 人工智能赋能电力 | 根据材料选意义型展开 | 一律用A需要B，倒置因果 |
| 明确策论文 | 主体以具体措施展开 | 三段故事后各贴一句建议 |
| 题干普通句无署名 | 用原句或无归属道理 | 编成名人讲话 |

## 4. 练习安排的正确使用

老师强调课前做、课中听、课后复盘；限时先完成；不盲目刷新题。训练可以先练结构，再练段落，最后完整限时。

课25重点复盘题：概括2、4、5、8、12、15；对策1、5、7；分析2、5、6；应用3、4、6、9；作文1—5。此处为老师课堂选题建议，不表示其余题无需掌握。

旧题新做时，检查自己能否不看答案说出材料结构、要点来源及取舍理由；不是只背出小标题。字数、时间和格式以具体考试要求和答题卡调整。
